# สนามแข่งโมเลกุล

สื่อการสอนกฎการแพร่ของเกรแฮม ครูฉายขึ้นโปรเจกเตอร์แล้วกดพานักเรียนไปทีละสเต็ป
นักเรียนเปิดตามในแท็บเล็ตได้ เว็บนิ่งล้วน ไม่มีระบบหลังบ้าน ไม่เก็บข้อมูลใคร

## 5 สเต็ป

| หน้า | สิ่งที่เกิดขึ้น | สิ่งที่นักเรียนต้องได้ |
|---|---|---|
| 1 คำถาม | ให้ห้องทายว่าเบาหรือหนักแพร่เร็วกว่า | มีคำทายของตัวเองก่อนเห็นคำตอบ |
| 2 แข่งกัน | หัวเรื่องเป็นคำถาม · เลือกคู่แข่งได้ 3 แบบ · ไม่มีตัวเลข ไม่มีป้ายชนะบนลู่ · จบแล้วขึ้นคำเฉลยพร้อมเทียบกับคำทายของห้อง | หนักกว่า = แพร่ช้ากว่า |
| 3 จับเวลา | 3 ชุด ชุดละ 3 ลู่ · จดผลลงใบงาน | มวลเพิ่ม เวลาก็เพิ่ม แต่เพิ่มไม่เท่ากัน |
| 4 สูตร | ก่อร่างจากคำพูดจนเป็น r₁/r₂ = √(M₂/M₁) + โทมัส เกรแฮม 1833 | อ่านสูตรออก แทนค่าเป็น |
| 5 ฝึกทำ | โจทย์ 3 ข้อ ไม่มีเฉลยบนจอ นักเรียนทำลงกระดาษ | ใช้สูตรทำโจทย์ได้ |

## เฉลยสำหรับครู (ไม่มีบนหน้าจอ)

**ข้อ 1** He กับ CH₄ — He เร็วกว่า **2 เท่า**
```
r(He) / r(CH₄) = √( 16 / 4 ) = √4 = 2
```

**ข้อ 2** แก๊ส X ช้ากว่า He 3 เท่า — X มีมวลโมเลกุล **36**
```
r(He) / r(X) = √( M(X) / 4 ) = 3
ยกกำลังสองทั้งสองข้าง : M(X) / 4 = 9
M(X) = 9 × 4 = 36
```

**ข้อ 3** NH₃ กับ HCl — ควันขาวเกิดใกล้ปลายด้าน **HCl**
```
NH₃ มวลน้อยกว่า จึงแพร่เร็วกว่า
r(NH₃) / r(HCl) = √( 36.5 / 17 ) = 1.47
ในเวลาเท่ากัน NH₃ เดินทางได้ไกลกว่า 1.47 เท่า
ทั้งสองจึงมาเจอกันเลยจุดกึ่งกลางไปทางฝั่งที่ช้ากว่า
```
ข้อนี้ต้องได้ทั้งตำแหน่งและเหตุผล ถ้าตอบแค่ "ใกล้ HCl" ยังไม่ครบ
ถ้าอยากถามต่อ: จุดที่เจอกันห่างจากปลาย NH₃ ประมาณ 59% ของความยาวท่อ

## สามชุดของด่าน 3

| ชุด | แก๊ส | มวลเพิ่ม | เวลาเพิ่ม |
|---|---|---|---|
| 1 | He 4 · CH₄ 16 · SO₂ 64 | ×4 ทุกขั้น | ×2 ทุกขั้น |
| 2 | H₂ 2 · O₂ 32 · CO₂ 44 | ×16 (H₂→O₂) | ×4 |
| 3 | He 4 · NH₃ 17 · HCl 36.5 | ×9 (He→HCl) | ×3 |

รวมสามชุดนักเรียนจะเห็น **4→2 · 9→3 · 16→4** ซึ่งชี้ไปที่รากที่สองตรง ๆ
He อยู่ทั้งชุด 1 และชุด 3 เพื่อให้เห็นว่าวัดซ้ำแล้วได้ค่าใกล้เดิม

ตารางบันทึกผลอยู่ในใบงาน ไม่ได้อยู่บนจอ เพราะการเทียบตัวเลขเป็นงานของนักเรียน ไม่ใช่ของหน้าจอ

**ใบงานไม่มีลิงก์จากในเว็บ** ครูเปิด [worksheet.html](worksheet.html) เองแล้วสั่งพิมพ์แจก
เพราะเป็นเอกสารของครู ไม่ใช่ของที่นักเรียนต้องกดเองระหว่างเรียน

## ตรวจสอบก่อนนำไปสอน

```bash
node tools/verify.mjs
```

ผลที่ต้องได้คือ "ทุกข้อผ่าน" — ชุดตรวจสอบครอบคลุมความแกว่งของเวลา ความสัมพันธ์ ×4 → ×2
ความเป็นเส้นตรงกับ √M ช่องว่างระหว่างคู่แข่งในหน้า 2 และเวลาที่ครูต้องยืนรอหน้าห้อง

ผลจริงจากการรัน 25 รอบต่อแก๊ส

```
He   มวล  4    9.4 วิ   ±4.8%
CH₄  มวล 16   18.8 วิ   ±4.4%
SO₂  มวล 64   37.4 วิ   ±4.4%
CH₄/He = 2.01 เท่า · SO₂/CH₄ = 1.99 เท่า
```

## สิ่งที่ต้องรู้ก่อนแก้ไข

**ตัวเลขเป็นการวัดจริง ไม่ได้สคริปต์ไว้** โมเลกุลแต่ละตัวได้ความเร็วสุ่มจากการแจกแจง
แมกซ์เวลล์–โบลต์ซมันน์ที่อุณหภูมิเดียวกัน ตัวที่หนักกว่าจึงช้ากว่าเอง เวลาที่วัดคือ
เวลาที่โมเลกุลครึ่งลู่ถึงเส้นชัย กดปุ่มแข่งใหม่แล้วตัวเลขจะไม่เท่าเดิม

**จำนวนโมเลกุล 800 ตัวต่อลู่คือความน่าเชื่อถือของบทเรียน** ที่ 120 ตัว เวลาที่วัดได้
แกว่ง ±11% การแข่งรอบเดียวอาจให้อัตราส่วน 3.2 เท่าแทนที่จะเป็น 2 เท่า ซึ่งครูอธิบายต่อไม่ได้
ความแกว่งลดตาม 1/√N จึงต้องใช้จำนวนมาก ถ้าจะลดเพื่อความลื่นบนเครื่องช้า ต้องรัน
`tools/verify.mjs` ดูผลกระทบก่อนเสมอ

**"ป้ายนักวิ่ง" คือสิ่งที่วัด** เวลาที่จับได้คือเวลาที่โมเลกุลครึ่งลู่ถึงเส้นชัย
ซึ่งเป็นตำแหน่งเดียวกับป้ายนักวิ่งพอดี ตอนป้ายข้ามธงคือตอนที่ขึ้นคำว่าชนะ
ห้ามเปลี่ยนอย่างใดอย่างหนึ่งโดยไม่เปลี่ยนอีกอย่าง ไม่งั้นจะกลับไปเป็นอาการ
"โมเลกุลถึงเส้นชัยแล้วแต่ไม่นับ" ที่ดูเหมือนโปรแกรมพัง

**คู่แข่งของด่าน 2 อยู่ที่ `DUEL_PAIRS` ใน config.js** ตอนนี้มี 3 คู่

| คู่ | อัตราส่วนเวลา | เวลาจริงหน้าห้อง |
|---|---|---|
| H₂ vs O₂ · ต่างกันมาก | 4.00 เท่า | 2.7 กับ 10.7 วินาที |
| He vs O₂ · ปานกลาง | 2.83 เท่า | 3.7 กับ 10.7 วินาที |
| NH₃ vs HCl · สูสี | 1.47 เท่า | 7.7 กับ 11.4 วินาที |

**ชื่อกำกับในตารางนี้ไม่ปรากฏบนหน้าจอ** ปุ่มบนจอมีแค่สูตรเคมี เช่น "H₂ vs O₂"
เพราะคำว่า "ต่างกันมาก" หรือ "สูสี" คือคำตอบ ต้องให้นักเรียนสังเกตเอาเองจากการแข่ง
(`label` ใน config ใช้แค่ในผลลัพธ์ของ `tools/verify.mjs`)

คู่สูสีคือคู่เดียวกับการทดลองท่อแก้วคลาสสิกและกับโจทย์ข้อ 3 ในด่าน 5
ถ้าจะเพิ่มคู่ใหม่ ให้รัน `tools/verify.mjs` ด้วย มันตรวจว่าทุกคู่ให้ผลตรงทฤษฎี
และคู่ที่สูสีที่สุดยังห่างกันพอให้เห็นด้วยตา (เกิน 1.25 เท่า)

**`speed` ใน config.js คือความเร็วในการเล่น** ตั้งไว้ให้การแข่งกระชับ (ลู่ช้าสุดราว 15 วินาที)
แล้วให้ครูกดปุ่ม **สโลว์โมชัน** เมื่ออยากให้นักเรียนดูละเอียด ปุ่มนี้กดได้ทั้งก่อนและระหว่างแข่ง
มีผลทันที ปรับตัวคูณได้ที่ `SLOW_FACTOR` `tools/verify.mjs` ตรวจช่วงเวลารอไว้ให้ด้วย

**โมเลกุลที่ผ่านเส้นชัยแล้ววิ่งออกนอกลู่ไปเลย** ไม่กองรวมกันอยู่ปลายลู่
(เวอร์ชันก่อนหน้าให้หยุดที่ปลายลู่ แล้วมันดูเหมือนแก๊สไปกระจุกตัวรวมกัน ซึ่งสื่อผิด)
ส่วนป้ายนักวิ่งหยุดที่เส้นชัย ไม่วิ่งตามออกไป

**หน่วยเป็นหน่วยจำลอง** กำหนดให้ kB = 1 ตัวเลขวินาทีบนจอไม่ใช่วินาทีจริงของแก๊สจริง
ใช้เปรียบเทียบกันเองเท่านั้น

**การเปลี่ยนแก๊สต้องล้างช่องผลลัพธ์เสมอ** `setGases()` เรียก `clearResults()` อยู่แล้ว
ถ้าลืมส่วนนี้ เวลาของชุดก่อนหน้าจะค้างอยู่ข้างแก๊สชุดใหม่ นักเรียนจะจดข้อมูลผิดลงใบงาน
โดยไม่มีสัญญาณเตือน — เป็นบั๊กที่เคยเกิดขึ้นจริงและตรวจพบตอนรีวิว

**ปุ่มปล่อยตัวของด่าน 3 ต้องกดสองครั้งเมื่อมีผลค้างบนจอ** กันครูกดพลาดทับข้อมูล
ที่นักเรียนกำลังจด ถ้ายังไม่มีผลอะไร กดครั้งเดียวเริ่มได้ตามปกติ
